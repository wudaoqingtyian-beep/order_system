# 订单管理系统测试用例

> 来源：order_system/testcases/order/*.yaml（16 条）+ tests/test_order.py（18 项）+ tests/test_data_factory.py（9 项）。
> 约定：统一响应 {code, message, data}，成功 code=0；失败 data 为 null。
> 错误码：1001 用户不存在，1002 用户名已存在，2001 商品不存在，2002 商品已下架，3002 库存不足，3003 数量非法，3004 明细为空，4001 订单不存在，4002 重复取消，9001 参数不合法。
