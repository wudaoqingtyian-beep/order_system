## 2. 用例覆盖

- 下单正常：单商品、多商品、库存刚好满足（边界值）；
- 下单异常：库存不足、数量 0/负数、明细为空、用户/商品不存在、商品下架；
- 取消：正常取消恢复库存、重复取消不二次恢复、取消不存在订单；
- 查询：订单不存在、商品/库存查询；
- 一致性：下单后与取消后接口库存与库内库存对齐，订单状态落库正确；
- 数据工厂：自动造数、完整流程、batch_id 唯一可查、清理无残留、批次隔离。

16 条 YAML 中 14 条含 db_eq 数据库断言，另 2 条（取消/查询不存在订单）为纯接口校验。

1. 无鉴权，用户身份由请求体 user_id 传入；
2. 未做真实并发测试，SELECT ... FOR UPDATE 仅有实现、无压测结论；
3. YAML 套件需手工启动服务，未接入 CI；
4. 默认测试与套件不可混在同一 pytest 进程执行；
5. 服务与数据工厂默认端口均为 8000，不可同时启动；
6. test_order.py 仍用简易 fixture 造数，未全量迁移数据工厂；
7. batch_id 时间戳精确到秒，理论上存在碰撞可能。
